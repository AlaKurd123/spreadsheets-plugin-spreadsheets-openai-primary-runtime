# Publish the register with GitHub Pages

The `docs` folder is a complete browser-only version of the register. It does not use Python, require a `config.json` file, or send student names anywhere. It creates the Excel file in the teacher's browser.

To publish it:

1. Put this project in a private school-owned GitHub repository.
2. In the repository, open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and the `/docs` folder, then save.
5. GitHub displays the site address. Share that address only with the staff who should use it.

Before sharing student data, ask Morley College IT to confirm that GitHub Pages and the chosen access settings are approved for staff use.

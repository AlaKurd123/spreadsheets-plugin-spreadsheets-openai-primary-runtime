# Temporary Register

A browser-only register for teachers to record attendance and download an Excel copy.

## Start it

1. Double-click `Start Temporary Register.cmd`.

The Excel file downloads to your usual Downloads folder. Attach the downloaded file to an email addressed to `ala.elkurd@morleycollege.ac.uk`. The register runs entirely in the browser and does not send or store student names online.

To publish a link for teachers, follow the instructions in `../docs/README.md`.
